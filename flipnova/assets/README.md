Пожалуйста, поместите файл иконки приложения сюда как `icon.png`.

Поддерживаемые форматы: PNG (рекомендуется с прозрачным фоном).

После того как вы поместите `assets/icon.png`, выполните в терминале:

```
flutter pub get
flutter pub run flutter_launcher_icons:main
```

Это сгенерирует иконки для Android и iOS на основе `assets/icon.png`.
