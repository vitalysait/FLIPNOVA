# FLIPNOVA
FLIPNOVA — мобильный мультитул для пентеста: ИК-пульт, Wi-Fi брутфорс (1000+ паролей) и DoS, Bluetooth глушилка/перехват, NFC ридер/эмулятор, генератор QR, трансляция экрана, Chameleon Ultra и плагины на Python/JS. Только для образования и тестирования своих устройств. Ответственность на пользователе.
