FLIPNOVA V2.1.1

💚 СПАСИБО DOLPHY
Часть идей и функций вдохновлена проектом Dolphy-App:
https://github.com/unvoiddd/Dolphy-App

FLIPNOVA — мультитул для пентеста и работы с железом на Android.
Один APK вместо кучи отдельных программ: NFC, Wi-Fi, BLE,
IP-камеры, ИК-порт, сеть, QR, терминал.

━━━ МОДУЛИ ━━━

📶 NFC
Чтение, запись и эмуляция NFC-меток. NDEF-записи (текст, URL),
информация о теге, запись в чистые метки, режим эмуляции,
HCE — эмуляция карты.

🌡️ IR REMOTE (Beta)
Управление техникой через ИК-порт. Команды NEC (POWER, MUTE,
VOL±, CH±, навигация), брутфорс кодов по функции, свои паттерны
с частотой несущей.

📶 WI-FI
Скан сетей: SSID, BSSID, RSSI, канал, защита.
Подключение к открытым и WPA-сетям из приложения.
Брутфорс пароля: встроенный wordlist (сотни паролей: типовые,
клавиатурные проходы, дефолты роутеров) + свои списки, живой лог,
STOP.
VAULT — хранилище найденных паролей: сохранение автоматом,
копирование, удаление, ручное добавление.
Deauth / Beacon Flood (best-effort, зависит от monitor mode).

🔵 BLE
Скан устройств: имя, MAC, RSSI, сервисы, сырые adv-данные.
Перехват пакетов цели, Jam/Kill (flood CONNECT_REQ + рекламные
берсты — срывает соединение), BLE Deauth.
Подключение к устройству, сервисы и характеристики.
BLE HID Keyboard — телефон как Bluetooth-клавиатура.

🌐 NETWORK
Ping, скан портов по диапазону, DNS lookup,
скан подсети на живые хосты.

📹 IP CAMERAS
Полный цикл: нашёл → открыл → подобрал пароль → сохранил → смотришь.

Поиск:
• SCAN NETWORK — скан подсети /24 по портам 80/443/554/8080/8000/8888
• SCAN ONVIF — обнаружение по WS-Discovery (multicast
  239.255.255.250:3702). Видит камеры, которые молчат на скан
  портов. Модель читается из SOAP GetDeviceInformation.
• Автоопределение названий камер (веб-title или ONVIF)
• Ручное добавление по IP + порт + имя

Работа с камерой:
• VIEW IMAGE — снимок: перебор путей (/snapshot.jpg, /image.jpg...),
  проверка magic-байтов JPEG/PNG, для RTSP авто-перебор HTTP-портов.
  Авторизация: твои креды → анонимно → 29 заводских учёток.
• ARCHIVE — архив записей: перебор /record/, /mnt/sd/, /mnt/mtd/,
  CGI hi3510; парсинг листингов, фильтр медиа (.mp4 .avi .mov .mkv
  .h264 .jpg), копирование ссылки тапом.
• BRUTE — брутфорс пароля: Basic auth, 12 логинов × ~130 паролей
  (заводские, hikvision/dahua/xiaomi) + свои списки. 6 потоков,
  прогресс, лог, STOP. Распознаёт страницы логина.
  Нашёл → автосохранение → OPEN CAMERA VIEW открывает с доступом.
• VAULT — хранилище доступов ip/user:pass; VIEW и ARCHIVE сначала
  пробуют сохранённые креды.
• CONNECT/DISCONNECT — проверка RTSP, статус ONLINE/OFFLINE.

📺 CAST
Поиск Chromecast/Google TV по BLE и сети, добавление по IP,
cast видео/экрана.

🎯 QR CODE
Скан QR с камеры, генерация своих (текст, URL, Wi-Fi креды).

🦎 CHAMELEON (Beta)
Интеграция Chameleon Ultra: слоты, чтение/эмуляция карт, BLE.

💻 HACKING
CLI-терминал: консоль с историей, DuckScript (Rubber Ducky)
пейлоады, JavaScript-скрипты, команды статуса системы.

🧩 PLUGINS
Датчики телефона: акселерометр, гироскоп, компас, свет,
приближение, барометр, батарея.

⚙️ SETTING
Акцентный цвет (неон + радуга), тёмная/светлая тема,
масштаб шрифта, калибровка иконок, стиль интерфейса.

━━━ ПРОЧЕЕ ━━━

🎨 Хакерский моноширинный UI (JetBrains Mono) с глитчами,
неоновые акценты, boot-экран со сканлайном, онбординг RU/EN,
компактный режим для маленьких экранов.

🔒 Сборка: обфускация + R8 + ProGuard.

📱 Android 6.0+ (API 23). NFC/IR/BLE — при наличии датчика.

⚠️ Для образовательных целей и аудита СОБСТВЕННОЙ инфраструктуры.
