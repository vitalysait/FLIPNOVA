# FLIPNOVA

**FLIPNOVA** — это мобильное приложение для Android, которое превращает ваш смартфон в универсальный мультитул для кибербезопасности, автоматизации и управления беспроводными интерфейсами. Вдохновлённое идеей Flipper Zero, приложение идёт дальше, добавляя сетевые атаки, трансляцию экрана, работу с NFC, генерацию QR‑кодов и открытую систему плагинов.

С FLIPNOVA вы получаете:
- ИК-пульт для управления техникой
- Wi-Fi брутфорс (1000+ паролей) и DoS-тестирование
- Bluetooth-глушилку и перехват соединений
- NFC Reader / Emulator для бесконтактных карт и меток
- Генерацию QR‑кодов (текст, ссылки, контакты, Wi-Fi и др.)
- Трансляцию экрана на Smart TV и проекторы
- Поддержку внешнего устройства Chameleon Ultra для продвинутого клонирования RFID/NFC
- Возможность писать собственные плагины на Python и JavaScript

Проект находится в активной разработке, некоторые модули помечены как `Beta`, но основные функции уже стабильны.

## 🔥 Функционал

### 1. IR Blaster (Beta)
Управляйте телевизорами, кондиционерами, проекторами и другой бытовой техникой через встроенный инфракрасный порт вашего смартфона. Поддерживается:
- Запись и воспроизведение ИК-сигналов
- Встроенная база кодов для популярных брендов
- Создание собственных пультов под любые устройства

*Требуется наличие ИК-передатчика в телефоне.*

### 2. Wi-Fi брутфорс + DoS-атака
- Подбор пароля к выбранной точке доступа по встроенному словарю (более 1000 самых распространённых паролей).
- Режим стресс-теста: отправка деаутентифицирующих пакетов (DoS) для проверки устойчивости сети к атакам.

*Работает на 2.4 ГГц сетях. Требуются права суперпользователя (root) на некоторых устройствах.*

### 3. Bluetooth глушилка и перехват
- Сканирование BLE-устройств вокруг
- Подавление сигнала (jamming) для тестирования защищённости Bluetooth-соединений
- Перехват и анализ BLE-трафика для выявления уязвимостей

*Функция перехвата может быть ограничена версией Android и наличием поддержки HCI-сниффинга.*

### 4. NFC Reader / Emulator
Используйте встроенный NFC-модуль телефона для:
- Чтения данных с бесконтактных карт, брелоков и меток (Mifare Classic, Ultralight, NTAG, и др.)
- Эмуляции выбранных карт для прохода в системы контроля доступа (при наличии соответствующего аппаратного обеспечения)
- Копирования и сохранения дампов карт для последующего использования

*Работает на устройствах с NFC-чипом. Для эмуляции некоторых типов карт может потребоваться root-доступ или использование внешнего устройства (см. п. 6).*

### 5. Генерация QR‑кодов
Быстро создавайте QR‑коды для любых нужд:
- Текст, ссылки, email, SMS
- Контакты (vCard)
- Настройки Wi-Fi (SSID, пароль, тип шифрования)
- Геолокация, события календаря
- Произвольные данные

Сгенерированный код можно сохранить в галерею, поделиться или отсканировать другим устройством.

### 6. Трансляция экрана
Одним касанием транслируйте изображение с экрана телефона на любое совместимое устройство:
- Smart TV (Miracast, Chromecast, DLNA)
- Проекторы
- Мониторы с поддержкой беспроводного приёма

### 7. Chameleon Ultra (Beta)
Интеграция с внешним устройством **Chameleon Ultra** — мощным эмулятором RFID/NFC. Позволяет:
- Клонировать карты доступа (125 кГц и 13,56 МГц)
- Эмулировать различные протоколы (Mifare Classic, Ultralight, EM4100, HID Prox и др.)
- Управлять устройством напрямую из приложения через Bluetooth или USB

*Требуется наличие оригинального устройства Chameleon Ultra.*

### 8. Плагины (Python / JavaScript)
Открытая архитектура плагинов даёт вам безграничные возможности. Вы можете:
- Написать скрипт на Python для автоматизации рутинных задач (например, парсинг данных, отправка запросов к API)
- Создать JS-плагин для добавления новых кнопок или сценариев в интерфейс
- Делиться своими плагинами с сообществом

Плагины загружаются динамически без пересборки приложения. Подробная документация по созданию плагинов доступна в папке `/docs`.

## 📲 Установка

### Системные требования
- Android 10 или выше
- Для IR Blaster — аппаратный ИК-передатчик (есть во многих Xiaomi, Samsung, Huawei)
- Для Wi-Fi и Bluetooth функций — разрешения `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION` (для сканирования BLE)
- Для NFC — наличие NFC-чипа и разрешение `NFC`
- (Опционально) Chameleon Ultra для работы с RFID/NFC
